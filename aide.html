Comment utiliser Originalis ?

Retrouvez ici les principales informations pour utiliser Originalis et vérifier vos documents.

📄 1. Vérifier un document Word

  1. Ouvrez la page « Vérifier ».
  2. Sélectionnez votre document Word.
  3. Attendez que le document soit chargé.
  4. Lancez la vérification.
  5. Consultez le résultat de l'analyse.

🔎 2. Comprendre l'analyse

Originalis analyse votre document afin d'identifier les similitudes avec le document de référence utilisé pour la comparaison.

Le résultat doit être interprété comme une indication destinée à vous aider à améliorer l'originalité de votre travail.

💡 3. Conseils pour améliorer votre travail

  • Reformulez les passages trop similaires.
  • Citez correctement vos sources.
  • Évitez de copier directement un texte sans référence.
  • Relisez votre travail avant de le remettre.

❓ Questions fréquentes

Quels documents puis-je vérifier ?

La version actuelle d'Originalis prend en charge les documents Word compatibles avec l'outil.


Originalis fonctionne-t-il sur téléphone ?

Oui. Originalis peut être utilisé depuis un téléphone ou un ordinateur disposant d'un navigateur compatible.
